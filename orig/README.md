# orig/

Put your own copy of the game here. Nothing in this directory except this
file and the `.sha1` list is tracked.

The target is 東方紅魔郷 1.02h: the files from the retail CD, with the
executable updated by the official `kouma_update102h.EXE` patch from
<https://www16.big.or.jp/~zun/html/th06.html>.

```
orig/th06_102h/            the CD's kouma/ directory
orig/th06_102h/東方紅魔郷.exe   updated to 1.02h
```

```sh
sha1sum -c th06_102h.sha1
```
